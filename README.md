# TurtleBot3 Autonomous Navigation Using A*

## Overview
This project explores autonomous mobile robot navigation using ROS 2 Humble and the TurtleBot3 Burger platform in a simulated environment.

The project focuses on A* path planning, occupancy grid maps, and the development of obstacle-aware navigation.

## Technologies
- ROS 2 Humble
- Python
- TurtleBot3 Burger
- Gazebo
- RViz2
- A* path-planning algorithm

## Repository Contents
- `a_star_planner.py` — A* planner implementation.
- `.gitignore` — Excludes generated files and local configuration.

Additional project files, maps, and documentation may be added as development progresses.

## Objectives
- Develop a path planner for mobile robot navigation.
- Explore grid-based environment representation.
- Integrate planning with robot pose and sensor information.
- Test navigation in simulation.

## Project Status
Work in progress. Navigation performance and goal-reaching behavior require validation in the simulation environment.

## Future Work
- Improve obstacle avoidance and path execution.
- Integrate with a saved occupancy map.
- Evaluate path length and goal-reaching success.
- Document simulation results with screenshots and videos.
